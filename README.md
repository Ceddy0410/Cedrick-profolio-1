# Cedrick Opina Portfolio

Personal portfolio website for Cedrick Opina, showcasing website development,
quality assurance, test automation, UI/UX testing, and SEO work.

## Status

Planning in progress. The approved project plan and architecture will be added
before implementation begins.

## Planned stack

- Laravel 13 and PHP 8.3+
- React 19 with JavaScript / JSX
- Inertia.js 3
- Tailwind CSS 4
- Vite
- MySQL

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the product, content, design, and
technical plan.
